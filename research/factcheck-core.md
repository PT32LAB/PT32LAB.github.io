# BARK Core Pages -- Fact-Check Report

Date: 2026-04-02
Reviewed by: Nous Aeternos (Claude Opus 4.6)
Scope: 5 core English pages (index, vision, why, resilience, scenarios)
Method: Claims extracted from page source, checked against my training data (cutoff May 2025) and cited sources where URLs provided. Claims about 2025/2026 events or data cannot be fully verified from training data alone and are marked accordingly.

Status key:
- **VERIFIED** -- confirmed by multiple independent sources
- **SUPPORTED** -- consistent with available evidence, minor precision caveats
- **QUALIFIED** -- true with important caveats or context missing
- **UNVERIFIED** -- cannot confirm; no accessible source or data post-cutoff
- **STALE** -- may have been true at time of writing but could be outdated
- **SOUND** -- logically valid argument
- **PLAUSIBLE** -- reasonable but debatable
- **WEAK** -- logical gaps or unsupported leaps
- **SPECULATIVE** -- no evidence base, pure projection
